Créer votre projet Firebase (gratuit, 5 min)

1
Aller sur console.firebase.google.com → Créer un projet → désactiver Analytics → Créer
2
Dans le menu gauche : Realtime Database → Créer une base de données → choisir l'Europe → Mode test (30 jours)
3
Copier l'URL de la base (format https://VOTRE-PROJET-default-rtdb.europe-west1.firebasedatabase.app)
4
Coller l'URL ci-dessous et appuyer sur Connecter
